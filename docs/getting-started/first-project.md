# Your first project

This walk-through builds `greet`: a small C++ library, a command-line tool
that uses it, and a test suite. By the end you will have configured, built,
tested and installed it, and consumed the installed package from a second
project that knows nothing about BESA.

Everything shown here is taken from BESA's own test fixtures, so it is known
to work with the current release.

## 1. The directory layout

```text
greet/
├── CMakeLists.txt
├── cmake/
│   └── options.cmake
├── src/
│   ├── include/greet/greet.hpp
│   └── lib/greet/greet.cpp
├── bin/
│   └── greet-cli.cpp
└── tests/
    ├── greet.t.cpp
    └── exit.fail.t.cpp
```

Three conventions are doing the work:

- `src/` is a **source unit**: `include/` holds public headers, `lib/` holds
  implementation files. Any depth of subdirectories is fine.
- `bin/` holds **one file per executable**. `greet-cli.cpp` becomes the
  target `greet-cli`.
- `tests/` holds **tests named `*.t.cpp`**. The `.fail.` infix marks a test
  that is expected to fail.

## 2. Declare the project options

BESA asks you to keep user-facing cache variables in one file and to call
`besa_finalize_options()` exactly once, after all of them are declared.

`cmake/options.cmake`

```cmake
set(BUILD_DEVTOOLS "none" CACHE STRING "Enabled development tools")
set(BUILD_WARNINGS "minimal" CACHE STRING "Warning policies")
option(BUILD_TESTING "Build tests" ON)

besa_register_options(GROUP build VARIABLES BUILD_DEVTOOLS BUILD_WARNINGS BUILD_TESTING)
besa_finalize_options()
```

`besa_register_options()` records the variables in the manifest so tools can
present them; it does not change their meaning. `besa_finalize_options()`
validates everything, prints the configuration summary and **freezes** the
configuration: from this point on you may create targets and tests, but you
may no longer declare options or features. (Why that split exists is the
subject of [How a BESA project is configured](../guide/lifecycle.md).)

## 3. Write the `CMakeLists.txt`

`CMakeLists.txt`

```cmake
cmake_minimum_required(VERSION 4.3)
project(greet VERSION 1.2.3 LANGUAGES NONE)
find_package(besa CONFIG REQUIRED)

include(cmake/options.cmake)
include(CTest)

besa_add_library(NAME libgreet TYPE STATIC INSTALL YES)
besa_add_directory(LIBRARY libgreet ROOT src TYPE cpp)

besa_add_subdirectory(DIRECTORY bin TYPE bin)
target_link_libraries(greet-cli PRIVATE greet::libgreet)

if(BUILD_TESTING)
  besa_test_add_directory(NAME tests PREFIX greet TARGET_LIST greet::libgreet LABELS unit)
endif()
```

A few things worth noticing:

- The project starts with `LANGUAGES NONE`. `besa_add_directory(... TYPE cpp)`
  enables `CXX` the first time a C++ unit is attached. You never enable
  languages by hand.
- `besa_add_library(NAME libgreet)` produces `libgreet.a` (not
  `liblibgreet.a`) and the alias `greet::libgreet`. `INSTALL YES` is the
  default; it is spelled out here for clarity.
- `TYPE STATIC` is optional. Without it CMake honours `BUILD_SHARED_LIBS`
  exactly as `add_library()` would.
- The executable from `bin/` is *not* linked to anything automatically.
  The `target_link_libraries()` line is required and intentional.

## 4. Write the code

`src/include/greet/greet.hpp`

```cpp
#ifndef GREET_GREET_HPP
#define GREET_GREET_HPP

#include <string>

namespace greet {

/** Returns a greeting for name. */
[[nodiscard]] std::string greet(std::string const& name);

} // namespace greet

#endif
```

`src/lib/greet/greet.cpp`

```cpp
#include <greet/greet.hpp>
#include <greet/version.hpp>   // generated by BESA

namespace greet {

std::string greet(std::string const& name)
{
  return "hello " + name + " from " + std::string(meta::to_string(meta::version()));
}

} // namespace greet
```

`<greet/version.hpp>` is not a file you write. BESA generates it from
`project(... VERSION ...)` and the release options, and attaches it to every
library in the project. It exposes `greet::meta::version()`,
`greet::meta::release()`, `greet::meta::build()` and friends as `constexpr`
functions — see [Versions and release metadata](../guide/versioning.md).

`bin/greet-cli.cpp`

```cpp
#include <greet/greet.hpp>
#include <iostream>

int main()
{
  std::cout << greet::greet("cli") << '\n';
}
```

`tests/greet.t.cpp`

```cpp
#include <greet/greet.hpp>

int main()
{
  return greet::greet("test") == "hello test from 1.2.3" ? 0 : 1;
}
```

`tests/exit.fail.t.cpp`

```cpp
int main() { return 1; }   // registered with WILL_FAIL; passes because it fails
```

## 5. Configure, build, test

BESA does not choose a C++ standard for you, so pass one:

```bash
cmake -S greet -B greet/build -DCMAKE_CXX_STANDARD=20 -DCMAKE_BUILD_TYPE=Debug
cmake --build greet/build
ctest --test-dir greet/build
```

```text
    Start 1: greet.greet.t
1/2 Test #1: greet.greet.t ....................   Passed
    Start 2: greet.exit.fail.t
2/2 Test #2: greet.exit.fail.t ................   Passed
```

Test names are the file path relative to the test directory with `/` replaced
by `.` and the `PREFIX` prepended. A file at `tests/parser/tokens.t.cpp`
would become `greet.parser.tokens.t`.

Want sanitizers? No CMake changes are needed:

```bash
cmake -S greet -B greet/build-asan -DCMAKE_CXX_STANDARD=20 -DBUILD_DEVTOOLS="asan;ubsan"
```

## 6. Install and consume

```bash
cmake --install greet/build --prefix /tmp/greet-prefix
```

Besides the library, headers and executable, the prefix now contains:

```text
lib/cmake/greet/greetConfig.cmake          # find_package(greet) entry point
lib/cmake/greet/greetConfigVersion.cmake   # SameMajorVersion compatibility
lib/cmake/greet/greetTargets.cmake         # the greet::libgreet imported target
lib/cps/greet/greet.cps                    # Common Package Specification
share/greet/install-manifest.json          # every installed file, relative to the prefix
include/greet/version.hpp                  # the generated version header
```

A consumer is ordinary CMake with no BESA dependency:

`consumer/CMakeLists.txt`

```cmake
cmake_minimum_required(VERSION 4.3)
project(consumer LANGUAGES CXX)
find_package(greet 1.2 CONFIG REQUIRED)

add_executable(consumer main.cpp)
target_link_libraries(consumer PRIVATE greet::libgreet)
```

```bash
cmake -S consumer -B consumer/build -DCMAKE_PREFIX_PATH=/tmp/greet-prefix -DCMAKE_CXX_STANDARD=20
cmake --build consumer/build
```
